# Library Management System (C++)

##  Description
This is a C++ based Library Management System project. It allows users to manage books, handle student reservations, and control access based on user roles.

##  Features
- **Admin Mode:** Add books, delete books, view inventory, and check activity logs.
- **Student Mode:** Search for books, view catalogs, and issue/return books.
- **Queue Management:** Manages waiting lists and student reservations.

##  Default Credentials
- **Role:** Admin
- **Password:** admin123

## How to Run
1. Download the `project.cpp` file.
2. Compile it using a C++ compiler (like g++):
   `g++ project.cpp -o library_system`
3. Run the executable:
   `./library_system` (or `library_system.exe` on Windows)
